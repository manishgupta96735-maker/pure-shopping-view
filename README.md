# Pure Shopping View

Create a very simple, clean 3D shopping-themed webpage.

IMPORTANT:

Do NOT create a full shopping app.

Do NOT create a dashboard.

Do NOT create multiple sections.

Do NOT use CoreAI branding.

The page should have only one main purpose:

A shopping-themed page with a video link.

DESIGN:

- Premium simple 3D shopping theme

- Bright soft background

- 3D shopping cart / shopping bag / a few grocery products

- Soft blue, green and subtle purple gradients

- Glassmorphism

- Smooth but minimal 3D animation

- Clean and uncluttered

- Responsive on desktop and mobile

CENTER OF PAGE:

Show a beautiful 3D shopping illustration.

Below it show:

“Shopping Video”

And a clickable glass/3D button:

▶ WATCH VIDEO

VIDEO:

Use this YouTube video:

https://youtu.be/dzuZ-_xscps?si=C6gCtqB3FARVT5ao

CRITICAL REQUIREMENT:

When the user clicks “WATCH VIDEO”:

- The video MUST open inside my website.

- Do NOT redirect to youtube.com.

- Do NOT open a new tab.

- Do NOT open the YouTube app.

- Do NOT show the normal YouTube webpage.

- Use the official YouTube IFrame Player API/embed.

- Open the video in a custom video modal/player inside my website.

- Keep the website visible around the video.

- Add a Close button.

- Add Play/Pause.

- Add Mute/Volume.

- Add Fullscreen.

- Add seek/progress control.

- Make the player responsive.

AUTOPLAY:

When the user clicks WATCH VIDEO, immediately open the video player and attempt autoplay.

If browser autoplay restrictions prevent autoplay with sound, start muted and allow the user to unmute.

FULLSCREEN:

The user must be able to make the video fullscreen using the fullscreen button.

IMPORTANT:

The YouTube video should be embedded inside my website, not opened as a YouTube page.

PAGE STRUCTURE:

3D shopping illustration

↓

“Shopping Video”

↓

[ ▶ WATCH VIDEO ]

That's it.

Keep the page extremely simple and premium.

Do not add unnecessary text, pricing, login, signup, testimonials, shopping lists, dashboards or extra features.
